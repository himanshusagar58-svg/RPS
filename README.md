# RPS
# Rock Paper Scissors Game

A simple Rock Paper Scissors game built using HTML, CSS, and JavaScript. The player enters their choice, the computer randomly selects its move, and the winner is determined according to the classic game rules.

## Features

* Interactive gameplay against the computer
* Random computer move generation
* Live score tracking for both player and computer
* Input validation
* Modern and responsive user interface
* Instant result display after each round

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## How to Play

1. Open the website in your browser.
2. Enter one of the following choices:

   * Rock
   * Paper
   * Scissors
3. Click the **Play** button.
4. The computer will randomly select its choice.
5. The result of the round will be displayed.
6. Scores are automatically updated after each round.

## Game Rules

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* Matching choices result in a draw
